# How to return an item

## Start the return online
1. Sign in to your account and open **My orders**.
2. Find the order and choose **Return an item**.
3. Select the item and a reason for the return.
4. We email you a returns reference and a postage label.

## Pack it
Put the item back in its original box with all accessories, then pack that box
inside an outer carton if you have one. Write nothing on the product box itself.
Attach the postage label to the outside.

## Send it
Drop the parcel at any Post Office or arrange a collection using the link in the
returns email. Keep your proof of postage until the refund appears.

## Track it
The returns reference appears in **My orders** and updates when the parcel
reaches us. See *Refund timescales* for what happens after that.

## No account?
If you ordered as a guest, reply to your order confirmation email with the word
RETURN and the item name, and we will send a label.
