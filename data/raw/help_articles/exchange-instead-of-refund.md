# Exchange instead of a refund

## When an exchange is available
You can ask for a replacement instead of a refund on any return, provided the
same item is in stock. This is usually the faster option for a faulty appliance,
because we can dispatch the replacement as soon as the return is scanned into
our warehouse.

## How to ask for one
Choose **Replace** rather than **Refund** when starting the return online, or
reply to the returns email saying you would prefer a replacement.

## Swapping for a different item
We can only exchange like for like. To move from a K7 to a K7 Pro, return the
K7 for a refund and place a new order. We cannot process a part-refund against a
different item.

## If the item is out of stock
We refund instead and email you to explain. We do not hold returns waiting for
stock.
