# Item damaged on arrival

## Report it whenever you notice
There is no time limit for reporting an item that arrived damaged. The 30-day
standard returns window does not apply — that window is for changing your mind,
not for goods that were faulty when they reached you.

## What we need from you
- Your order number
- Which item is affected
- A short description of the damage

Photographs help but are not required. Do not throw away the packaging until the
return is complete, as the courier may need to inspect it.

## What happens next
We send a prepaid return label by email, usually within one working day. Return
postage is free for damaged goods. See *Return postage costs*.

Once the item is back with us we inspect it within 2 working days and issue a
full refund, or send a replacement if you would prefer one. See *Exchange
instead of a refund*.

## If the box arrived visibly crushed
Where possible, refuse the delivery and let the courier return it. That gets the
refund started without you needing to arrange a return at all.
